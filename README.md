**Автор:** Плумаки Анна Янис

## Описание программы

Random Password Generator — это графическое приложение (GUI) на Python с использованием библиотеки tkinter.  
Программа позволяет генерировать случайные пароли с настраиваемыми параметрами:

- длина пароля (от 4 до 64 символов)
- использование цифр
- использование букв (A-Z, a-z)
- использование спецсимволов (!@#$%^&*)

Все сгенерированные пароли сохраняются в историю (файл `password_history.json`) с указанием длины и даты создания.

## Требования для запуска

- Python 3.7 или выше
- Встроенные библиотеки: `tkinter`, `random`, `string`, `json`, `datetime` — дополнительной установки не требуют

## Как запустить

```bash
git clone https://github.com/plumakianna-prog/password-generator.git
cd password-generator
python password_generator.py
```

## Как пользоваться

### Выберите длину пароля:
Передвигайте ползунок (от 4 до 64)
Или введите число вручную в поле рядом с ползунком

Отметьте нужные типы символов:
✅ Цифры
✅ Буквы
✅ Спецсимволы
Нажмите кнопку «Сгенерировать пароль»

### Скопируйте пароль:
Нажмите «Копировать в буфер обмена»

### Просмотр истории:

Все пароли отображаются в таблице внизу
Показываются последние 20 записей (всего хранится до 100)

### Управление историей:

Очистить историю — удаляет все сохранённые пароли (с подтверждением)
Экспортировать историю — сохраняет все записи в отдельный JSON-файл с меткой времени

## Обработка ошибок

### Программа устойчива к различным ошибкам:

1. Файл истории повреждён (неверный JSON)
Показывает сообщение и создаёт новую историю

2. Файл истории имеет неверную структуру
Сообщает об ошибке и создаёт новую историю

3. Нет прав на запись файла
Показывает предупреждение, программа продолжает работу

4. Ввод нечислового значения длины
Сообщение об ошибке, возврат к предыдущему значению

5. Длина меньше 4 или больше 64
Сообщение об ошибке, коррекция значения

6. Не выбран ни один тип символов
Сообщение об ошибке, генерация отменяется

## Примеры работы

### Пример 1: простой пароль только из цифр

Длина: 6
Цифры: ✅
Буквы: ❌
Спецсимволы: ❌

Результат: 482739

### Пример 2: сложный пароль

Длина: 16
Цифры: ✅
Буквы: ✅
Спецсимволы: ✅

Результат: aB3!xL9@qR8#mN2$

### Пример 3: ручной ввод длины
Пользователь вводит 20 в поле ввода → ползунок автоматически перемещается на 20 → генерируется пароль длиной 20 символов.

### Пример 4: ошибка при пустом наборе символов
Если не выбрать ни один тип символов, программа покажет сообщение:
"Ошибка генерации: выберите хотя бы один тип символов!"

### Пример 5: очистка истории
Нажмите кнопку «Очистить историю»
Подтвердите действие в диалоговом окне
История очищается, таблица становится пустой


Сохранение	Сгенерировать → закрыть → открыть снова	История загружается корректно
Очистка истории	Нажать "Очистить историю" → подтвердить	История пуста, файл обновлён
